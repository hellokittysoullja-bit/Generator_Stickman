# Облик ролика

- `style/` — 1-3 кадра в том стиле, каким должен выглядеть ролик. Уходят в модель картинок на каждом кадре.
  Лучше кадры без людей, похожих на героя: иначе модель может взять героя из образца стиля.
- `hero.png` (или .jpg/.webp) — главный герой, необязательно. Уходит в модель только на кадрах, где он нужен.
  Чисто: один персонаж целиком, на ровном светлом фоне, ничего лишнего по краям.
  Лучше лист из 2-3 поз (стоит, сбоку, в движении): по одной позе модели склонны копировать её
  (замер 30.09: Qwen-Image сажал героя почти везде, потому что на референсе он сидел).

Другая папка для другого канала — переменная `LOOK_DIR` в `.env`.

## `states/` — эталоны героя по состояниям (PNG без фона)

**Правило эталонов (решение владельца 21.10, нарушать нельзя).** Эталоны одного персонажа отличаются ТОЛЬКО мимикой:
глаза открыты или закрыты, форма рта, наклон бровей. Всё остальное одинаково во всех эталонах, до деталей:
- **язык** — один и тот же: маленький, светло-розовый, с бороздкой посередине, как на эталоне сайта
  (`Naparnik-Site-ADHD/public/mascot/states/happy-tongue.png`). Большой язык на пол-рта — брак;
- **рот** открывается не шире, чем на этом эталоне;
- **глаза** того же размера, с тем же числом бликов (один блик; два блика в глазу — брак);
- уши (левое загнуто), полоски щёк, лапы, хвост, огонёк — те же, той же формы и размера.

Снят как брак: `hero-happy-tongue.png` (21.10) — язык вдвое больше эталонного, по два блика в глазах. Вместе
с ним сняты исходник лица куклы `experiments/alive_cat/doll/faces/happy_src.png` и заплатка `happy_mouth.npz`:
кукла без эталона веселого лица не показывает язык, пока не появится правильный эталон.

**Как проверять новый эталон до того, как класть сюда:** положить рядом с нейтральным и с эталоном сайта
в одном масштабе и сравнить глазами язык, рот, блики, уши; генерировать с двумя референсами (нейтральный кот
и кадр с нужным ртом), иначе модель рисует свой рот.
