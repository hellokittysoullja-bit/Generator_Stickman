# Рилс 56 «чемодан» — общее задание агентам (автономно, БЕЗ генерации картинок, только код)

Тема (вид Х, хайп-комедия без исследований, женский голос Alisa; карточки подписки нет, призыв «Напиши кот…» в последней
строке): Дима собирается в отпуск за час до выхода → один свитер → три свитера → зонт, фен и сковородка → чемодан не
закрывается, Дима садится сверху → закрылся, внутри оказался кот → кота достали, а паспорт остался на полке → теперь Дима
собирает чемодан за день и по списку → «Напиши кот, если ты тоже собираешься в последний час».
Папка: `videos/56_chemodan/story/` (`script.txt`, `voice/words.json`, `shots.json` — 16 планов, `sound.json` — 24 звука,
конец 31.2 с). Формат, стиль, Дима и кот — как в `docs/story_brief_29.md`, `docs/story_brief_55.md` (читать целиком).
Комедия: сжатие и отскок (squash/stretch), удары камеры на словах, кот с реакцией (укор, отряхивается, довольный).

## Контракт клипа
`clips/<id>.mp4` (в git не идёт): 1080×1920, 30 к/с, H.264 CRF 16, yuv420p, без звука, без субтитров. Клип покрывает время
ролика от max(0, t0 − 0.2) до t1 + 0.2 (кадр k = max(0, t0 − 0.2) + k/30; s16 — до 31.2). Анимация от общего времени ролика,
удары на словах по `voice/words.json` (индексы слов в `sound.json`). Низ 1300–1560 — под субтитры: главное действие выше.
Каждый план двигается с первого кадра (камера и сам рисунок). Печатных надписей на рилс не больше одной: только рукописное
«кот» на s16, остальное штрихи; мелкого текста нет (часы без цифр, календарь штрихами, список — штрихи и галочки, паспорт
без букв, только кружок-герб). Дима — горчичное худи, лохматый, щетина, мешки под глазами; кот — `look/hero.png` (ЛЕВОЕ от
зрителя ухо загнуто, огонёк на кончике хвоста). Без двойных контуров, полупрозрачных фигур, кривых рук; лист кадров глазами
для каждого клипа, код сохранять в репозиторий сразу.

## Как избежать промахов рилса 55 (обязательно)
- **Рука Димы при крупном плане:** рука — не больше головы по размеру и той же толщины линий, что у тела; на крупных планах
  рисовать кисть/пальцы отдельно по размеру кадра (не растягивать руку полной фигуры). Сверить лист с плана «в полный
  рост» рядом: кисть ≈ 1/3 лица.
- **Ноутбук-«тостер»:** в этом рилсе ноутбука нет; вместо него любые твёрдые предметы (чемодан, сковородка, фен, зонт) —
  с узнаваемым силуэтом и пропорциями: сковородка — круг с длинной ручкой, фен — пистолетный силуэт с соплом, зонт —
  купол и крючок; не «коробки с ручками».
- **Одинаковые фигуры с пустыми лицами:** у Димы на каждом плане своя мимика (брови, рот, зрачки; паника, самодовольство,
  сомнение, натуга, облегчение, укор, спокойствие); лицо никогда не пустой овал. Кот тоже с реакцией, не иконка.
- **Ночной кот коричневый:** действие днём, всё при дневном свете; цвет кота как в `look/hero.png` (чёрный с рыжими
  отметинами по эталону), никаких общих тонировок, которые красят его в коричневый. Проверить цвет шерсти пикселем.
- Не больше двух похожих планов подряд: s07 (замок) → s08 (Дима в полный рост, сбоку) → s09 (молния предельно крупно)
  чередуют масштаб; s03 крупно, s04 средний, s05 сверху.
