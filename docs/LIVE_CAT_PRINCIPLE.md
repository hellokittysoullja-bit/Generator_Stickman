# Как делаются эталоны кота и как их оживляют

## 1. Эталонные PNG (без фона, высокое качество)
1. **Референс.** Оригинальный рисунок кота на белом фоне (`reference.png` у сайта, `look/hero.png` у героя видео).
2. **Генерация.** `cx/gpt-image-2`, качество `high`, размер 1536x1024 (281 тыс. токенов за кадр). Запрос `output_format: png` и в промпте «настоящий альфа-канал, без бумаги, без тени, без шахматки». Параметр `background: transparent` шлюз отклоняет (400).
3. **Мимика.** Промпт «оставь всё один в один, меняй только лицо». Для точной мимики модели даётся второй референс: кадр, где нужный рот или глаза уже нарисованы (язык: `gen/mouth-open.png`). Без него язык выходил крупным и коралловым.
4. **Прозрачность.** Модель вернула настоящий альфа-канал в 4 кадрах из 6. Где пришла нарисованная «шахматка» или белый фон, фон убирается матированием (`matte.py`): цвет у края берётся у ближайшей твёрдой точки меха, прозрачность считается по тому, насколько пиксель темнее белого. Поэтому белой каймы нет. Дыры внутри хвоста и пряди убираются отдельно.
5. **Проверка.** Каждый PNG кладётся на тёмный, белый и пурпурный фон, края смотрятся крупно.
6. **Честный предел.** Модель перерисовывает кота заново, а не копирует: средняя разница с оригиналом 6,7 из 255, около 12% пикселей отличаются (штрихи меха и усов). Точная копия оригинала без перерисовки — только `original-cut.png` (вырезка исходника).

## 2. Как они становятся живыми (кукла героя в видео)
Кукла — это не анимация кадров, а **слои одного рисунка + движения кодом**:
- **Слои:** мех без глаз (дорисован LaMa), радужка, зрачок, блик, голова, ухо, хвост, огонёк.
- **Автоматическая жизнь** (`doll_rig.plan`, по зерну, повторяемо): моргание (быстро вниз, медленнее вверх, иногда двойное), взгляд за предметом, наклон головы, подёргивание уха, хвост шумом fBm, огонёк, дыхание.
- **Эмоция = заплатка лица + движение тела, а не новая картинка кота:**
  - Веселый: заменяется только рот (язык), глаза остаются живыми — моргание и взгляд работают. Звёздочки рисуются кодом: мерцают, плывут, выскакивают с перебором.
  - Сон: веки смыкаются, дуги ∩ проявляются поверх меха без глаз (только чернила дуг), голова опускается на 3,4°, дыхание глубже и реже, Z растут и поднимаются по очереди.
- **Переходы плавные:** 0,3 с у веселого, 0,7 с у сна. Эмоция живёт дольше клипа, пока её не сменят.
- **Заплатка** вырезается из сгенерированного кадра: кадр совмещается с эталоном по зелёным глазам или по щекам и носу, тон меха подгоняется по кольцу вокруг заплатки, чтобы шва не было (`faces_build.py`).
- **Кадры без эмоции** байт в байт прежние (сверено).

## 3. Кот на сайте (WebGL)
Отдельный путь: части (тело, рука, голова, глаза, уши, хвост) нарисованы GPT-Image-2, посажены на кости с весами и рисуются линейным скиннингом в WebGL (`lib/rig`). Дыхание, пружины ушей и хвоста, моргание, взгляд за курсором, взмах, прыжок.
