# Рилс 60 «темнота» — общее задание агентам (автономно, БЕЗ генерации картинок, только код)

Тема (вид М, миф, женский голос Alisa; карточки подписки нет, призыв «Напиши кот…» в последней строке): «Говорят, если читать
в темноте, испортишь зрение» → Дима в детстве читал под одеялом с фонариком, мама ругалась → на самом деле зрение не портится →
глаза устают, слезятся, болят, потом отдыхают → неприятно, но проходит, когда поспишь или включишь свет → важнее давать глазам
отдых и смотреть вдаль → теперь Дима читает при лампе, каждые полчаса смотрит в окно → кот смотрит в окно вместе с ним, хотя ему
не нужно → «Напиши кот, если тебя тоже ругали за чтение под одеялом». Правду называем простыми словами, без «учёные доказали» и цифр.
Папка: `videos/60_temnota/story/` (`script.txt`, `voice/words.json` не менять; `shots.json` — 18 планов, `sound.json` — 25 звуков, конец 32.15 с).
Формат, стиль, Дима и кот — как в `docs/story_brief_29.md`, `55`–`59` (читать целиком; свежий образец — `docs/story_brief_59.md`).

## Контракт клипа
`clips/<id>.mp4` (в git не идёт): 1080×1920, 30 к/с, H.264 CRF 16, yuv420p, без звука, без субтитров. Клип покрывает время ролика от
max(0, t0 − 0.2) до t1 + 0.2 (кадр k = max(0, t0 − 0.2) + k/30; s18 — до 32.15). Анимация от общего времени ролика, удары на словах по
`voice/words.json` (секунды слов — в `what` каждого плана, индексы — в `sound.json`). Низ 1300–1560 под субтитры: главное действие
выше. Каждый план двигается с первого кадра (камера и сам рисунок). Рендер клипа — один процесс. Печатных надписей не больше одной:
рукописное «кот» на s17 (живое перо, строчными, неровно, тонкий штрих, «о» с петлёй; в 55–59 читалось как печатные «KOT»; основа
`videos/57_voda/story/ext_c`, `59_podarok/story/ext_e`). Всё остальное штрихи и значки без букв и цифр. **Книга без букв**: страницы
штрихами. Мелкого текста нет. Взрослый Дима — горчичное худи, лохматый, щетина, мешки под глазами. Маленький Дима — отдельный детский
персонаж (меньше, круглее голова, лохматый, пижама), не уменьшенная копия взрослого. Без двойных контуров, полупрозрачных фигур,
кривых рук; лист кадров глазами для каждого клипа, код сохранять и пушить сразу.

  кардиган, морщинки у глаз, мимика: строгая, улыбка), кот (`look/hero.png`). Функции с параметрами позы, мимики, масштаба. Основа —
  `59_podarok/story/common/*`, `57_voda/story/ext_a`, `55_nachni/story/ext_a`, `56_chemodan/story/ext_c` (`cat.py`, `cathang.py`).
- Остальные группы начинают с клипов, которым общий файл не нужен (глаз, комната, даль), затем `git pull` и импорт; своих копий
  предметов и людей не рисовать. Пока файла нет, берут существующий код (`59_podarok/story/ext_*`, `57_voda/story/ext_*`).

## Промахи рилсов 55–59, которые нельзя повторить
- **Руки не держат предметы:** хват пальцами, пальцы огибают предмет (книга, фонарик, выключатель), большой палец виден, не плоская ладонь.
- **Руки не длинные прямые палки:** локоть и плечо, пропорции предплечья; рукав не толще предплечья, кисть ≈ 1/3 лица на крупных планах.
- **Дима мелкий на общих планах:** на s13, s14, s17 фигура взрослого Димы не меньше ~45 % высоты картинки; не вечный присед.
- **Кот не чёрный:** почти чёрный #2a2d30–#3b4143 как `look/hero.png`, ЛЕВОЕ ухо загнуто, оранжевое только огонёк на хвосте; не скользит, а
  шагает и запрыгивает; проверить цвет шерсти пикселем.
- **«кот» печатными буквами:** только живой рукой, штрихи разной толщины, буквы разной высоты, строка с наклоном.
- **Одинаковые лица и позы:** у каждого плана своя мимика (азарт, зевота, боль, облегчение, лень); мама не копия Димы; кот с реакцией.
- Не больше двух похожих планов подряд: чередовать масштаб и место (ночная детская → глаз → мама в проёме → глаз с галочкой → глаз
  макро → окно с далью → торшер → подоконник → кот → финал).
