# Задание читателю расшифровок (волна 9, хуки)

Контекст. Фабрика немых рилсов 9:16 (~40 с) на русском: рисованный чёрный кот с огоньком на хвосте («Напарник» —
бесплатный сайт, где кот «сидит рядом», пока человек начинает дело; аудитория — люди с СДВГ и с похожими
симптомами без диагноза). Голоса пока нет: только субтитры, рисунки, движение камеры, 4 звука (нарастающий riser
с 0 с с пиком на 1.65 с, свист, низкий свист, «ох»). Владелец недоволен хуком последнего рилса («Письмо. День
третий.» → «Ответить — пять минут.»): «с него уйдёт любой человек, он не приковывает внимание». Нужна база, по
которой КАЖДЫЙ следующий хук будет сильным.

Твоя задача: прочитать ЦЕЛИКОМ, от первой до последней строки, каждую расшифровку из твоего списка (файл bundle).
Не пролистывать, не судить по началу. Расшифровки — автосубтитры YouTube (без пунктуации, бывают ошибки
распознавания). Читай файл Read-ом частями, пока не дочитаешь. Прежние выжимки базы НЕ используй — смотрим заново
другим взглядом.

Линза (что выписывать; всё с дословной цитатой-примером из ролика, переведённой на русский, и id ролика):
A. ХУК 0–3 с: формулы фраз; конкретные примеры хуков, которые автор приводит или разбирает (было → стало, с цифрами,
   если есть); визуальный хук (первый кадр, движение, предмет, лицо/глаза, текст на экране, его размер и место);
   звуковой хук; «совмещение» визуала, текста и слов; длина хука; что убивает хук (вода, контекст, приветствие,
   медленный старт, непонятно «про что»); ставки, конкретика, отрицательная формулировка, «ты»-обращение, контраст.
B. УДЕРЖАНИЕ 3–10 с и дальше: закрепление хука, ре-хуки, «но/поэтому», открытые петли, когда давать ответ, темп.
C. КОГНИТИВНЫЙ ДИССОНАНС и смена убеждения: как ломать убеждение зрителя, контринтуитивные утверждения, «миф/правда»,
   как не вызвать отторжение.
D. ПСИХОЛОГИЯ АУДИТОРИИ: идентичность, называние боли, статус, страх упустить, желание, эмоции; любые приёмы
   влияния и манипуляции, о которых говорят (выписывать все, даже тёмные, с пометкой «тёмный приём» — решение
   брать или нет принимаем позже, по правилам: обман и давление не берём).
E. ВОРОНКА из короткого видео: призыв, переход в профиль/сайт/личку/Telegram, «невидимая» воронка, лид-магниты, цифры.
F. ЦИФРЫ И ДАННЫЕ: любые числа удержания, конверсии, A/B-тесты — с тем, откуда автор их взял.
G. ЧТО ПРИМЕНИМО к немому рисованному рилсу с котом (без лица автора, без голоса).

Формат вывода — файл, путь которого указан в задании, по-русски:
1) Для КАЖДОГО ролика из списка — раздел «## id — канал — тема (N слов прочитано целиком)» и пункты по линзе A–G
   (пустые буквы пропускай; если в ролике по линзе нет ничего — одна строка «вне линзы: о чём ролик»). Цитаты дословно.
2) В конце — «## Сводка пакета»: 15–30 самых сильных находок по хуку (A), отсортированных по силе доказательства
   (данные > кейс с цифрами > мнение), каждая — с id роликов; противоречия между авторами; 10 лучших примеров хуков
   дословно (оригинал + перевод).
Не выдумывай; если автор не дал цифр — так и пиши. В ответе (не в файле) — 10 строк: сколько роликов прочитано
целиком, 5 главных находок по хуку, путь файла.
