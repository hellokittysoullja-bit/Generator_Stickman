# 02 — что меняется в v6

## §5 монтаж (строки 1–180)
- M1 MATCH CUT по конверту (Tim Runia J0ydlAqg6_8, Jonny Duncan, LISTOPADOV: графический — форма в той же позиции кадра = ход
  времени). Конверт есть на ВСЕХ семи рисунках. → склейки между рисунками делать конверт-в-конверт на одном месте экрана:
  f6 (брошен) → f3 (в кляксах) → f1 (в кольце следов) → f4/f7 (открыт) → f5 (на столе, кот читает). Так «неделя» и путь видны
  без слов, и фокус не прыгает через склейку (5.3, 6 источников).
- M2 Точка внимания на одном месте экрана через склейку (Isaac, Just Create Ryan, Sleepy, Хохлов): глаза кота / конверт.
- M3 Стресс героя — экстремальный крупный план морды (IM Toolkit): на «страшно» — тесный крупный кот f3 (лапа у рта, глаза).
- M4 Кулешов «реакция — источник — реакция» (LISTOPADOV, Dylan Reynolds): конверт → морда кота → конверт.
- M5 Общий → крупный без соседней ступени; cut in / cut back для акцента (vidIQ).
- M6 Деталь вместо слов (HillierSmith «спрятан, сдувают пыль»): кляксы на конверте f3 = «висит давно»; кольцо следов f1 =
  «ходишь кругами» — уже на своих словах, держать.
- M7 Карта энергии хука (Tim Runia): напряжение со звуком → пауза 1 с → полная энергия → передышка длинным планом →
  нарастание → разрядка. Расставить в v6 явно: передышка — после «строчки» (2) или после «страшно» (4).
- M8 Звуковой переход через 2 склейки склеивает планы (Tim Runia, Старый Спорт): один swoosh_deep/riser через серию
  конвертов (M1) — одно событие «неделя».
- M9 Переход только с назначением (Herman Huang): хлёст — только на смене времени (неделя → «три дня назад» кота).
- M10 Ускоряющаяся серия (Matt Loui) — «время летит»: серия конвертов M1 ускоряется. Ограничение кода ≤10 смен рисунка за 30 с —
  серия из 3 рисунков влезает, если убрать лишние смены в другом месте.

## §5.12–7.4 (строки 180–350)
- M11 ЗАЧЁРКИВАНИЕ на произнесённом слове + сверху новое слово (Aeovisuals oUU1Lj7hcNU, 6.5; плюс 4 пункта инвентаря):
  нового fx нет → сделать `strike` в reel.py за флагом (правило владельца: новые визуальные элементы — за флагами).
  Место: «ленивый» рукописно на бумаге → красная линия на «плевать» → сверху «страшно» на «страшно».
- M12 Порядок цепочки подчинён смыслу (Vox): круг → стрелка → второй круг. У нас пометки независимы; в v6 зачёркивание и
  новое слово — одна цепочка.
- M13 Кот «вырастает» из-за предмета/линии пола, а не появляется (Edit with Panda, Zeven 7), падение с отскоком
  (Wampus): вход куклы на «рядом» — вход снизу из-за линии пола. Проверить, умеет ли reel.py (doll enter).
- M14 Ключевое слово группы — отдельным субтитром из одного слова (Steven Steward): «плевать», «страшно», «рядом», «бесплатно».
- M15 Зазор 2–4 кадра между группами (StudioBinder) vs встык (Chriss Boustedt) — гипотеза, не трогаю.
- M16 Рукописное слово как акцент в строке субтитров (8 источников) — у нас рукописное только на рисунке; mark «бесплатно» есть.

## §7.5–8.4 (строки 350–440)
- M17 ОДНО ЧТЕНИЕ ЗА РАЗ (TomsProject, Joseph ×2, StudioBinder): где на экране рукописный текст — субтитр не дублирует.
  v5: mark «бесплатно» стоит одновременно с субтитром «бесплатно» → дубль. → рукописное слово выходит в немую паузу
  после слова (gaps), когда группа субтитров уже ушла; то же для зачёркивания («ленивый» пишется, когда субтитр уже сменился).
  Проверить в reel.py, гаснет ли субтитр в паузе.
- M18 Один акцентный цвет (8 источников) vs наши жёлтый (активное) + оранжевый (ключевое) — открытый вопрос владельцу, не трогаю.
- M19 Звук невидимого (LISTOPADOV, Film Editing Pro): тяжёлое чувство — глубокий swoosh_deep на «страшно»? — только если смысл;
  swoosh_deep ≤3 и ≥4 с — бюджет.
- M20 Звуковой стиль один (Herman Huang) — 4 звука владельца, ок.
- M21 Пик whoosh на кадр макс. смаза — есть.
- M22 Riser перед ценностью, конец райзера = раскрытие (SalimEdits, Joseph, Clumzzy): второй riser под «Открыл,» → пик на
  «две строчки» (E4).
