## §8.4 Конфликты (стр. 793–855)
- Все роли (мама, муж, учитель, врач, начальник, знакомые) говорят одно: «просто», «возьми себя в руки», «отговорки»,
  «придумала», «у всех так». Кот не произносит ни одной и не играет ни одной роли.
- Голос партнёров тоже есть (устали) — «ЭТО НЕВЫНОСИМО», «пилю как мать близнецов» — партнёр = второй покупатель
  (рилс для того, кто рядом: «как понять, что он не специально»). Пересылают, чтобы объясниться.
- Матери: «репутация матери-лентяйки» [629]; «отправили всем родным» [11].

## §15.1–15.2 Картинка, текст, звук, монтаж (стр. 3863–4020) — ДОРОГИЕ ЭФФЕКТЫ по данным
- Плохое слово → красный оттенок + звук; «иногда важно, что убрать». Хук-текст стоит с первого кадра; кинетика после.
- Гаджи-сцены: медленный наезд/панорама всегда; персонаж взаимодействует с окружением; повторяющийся «элемент главы»;
  палитра 60/30/10; UI «быстро начинается — медленно кончается».
- Ключевое слово крупнее и цветом, из размытия с фокусом за 0,3 с; свисты на каждое движение камеры, riser кончается вместе с движением.
- Анимация: не линейно; влёт с перелётом, растяжение при падении, сплющивание при касании, затухающий наклон, размытие в движении.
- Минимализм: светлый фон, виньетка, одна сущность в центре, вход из размытия 20→0 за 20 кадров, наезд 130→100% с поворотом 10°→0;
  персонаж «выпрыгивает» из рамки; пик скорости перехода — на «дроп»; предметы-метафоры.
- Звук: событие = свой звук (деньги падают — звук денег); не «поп» на каждый субтитр; «дорого = меньше, но лучше»; «мне нужен
  этот эффект или мне скучно?»; свисты на движение, басы на удар, тихие щелчки на UI; щелчок при появлении текста — «дороже».
- Склейки: J-cut, match cut по форме, смэш-кат «громкое → тихое».
- Иерархия слов: ключевое 200–250 px, остальные ~70%.
- «Монтируй, будто движение сквозь густой воздух»; обратный «hit» перед вопросом; кассовый аппарат на слово о деньгах.
- Звук слоями: движение → эффекты → эмоция; riser кончается ровно на наезде следующей сцены + тяжёлый свист; два звука на событие;
  серия одинаковых звуков убывает −12/−18/−22 дБ; ФОЛИ: карандаш на рисующиеся линии, щелчок ручки на ключевое слово, маркер на полосу.
- Кулешов + «Тихое место» (реакция → игрушка → реакция = страх). Двойная склейка — удар.
- Рисованное видео (Doodly): реквизит передаёт то, чего нет в тексте (часы = время); крупный план стресса интимнее; паузы на размышление.
- Один цвет выделения; «смягчайте анимации, одним ритмом»; визуал вместо слов; каждая фраза — картинка; звук на событие.
- ★ Кадры без слов: «грустный человек → пустой карман» — понятно без слов; кадр 1–3 (max 4) с; «наш шрифт — только рукописный —
  очень вовлекающе».
- Шрифты: скруглённые — дружелюбные; ПРОПИСНЫЕ — громко/зло; личные уязвимые ролики — строчными; центр — эмоция.
- Субтитры: 1–2 сильных слова цветом; без точек; безопасная зона; лишняя секунда тишины на стыке — ошибка; глаза героя на одной
  высоте через склейку.
- Звук: пик свиста на пике размытия; фактурные звуки (клики, карандаш, бумага, маркер) «оживляют мёртвые анимации — самая большая
  разница»; решить заранее, где ожидание, где разрядка; реверс свиста = удар, обрезанный = riser; панорама по движению;
  эффект не в тональности — фальшь; тот же свист 15 раз — заметят.
- Камера «быстро в начале, потом замедляется»; приглушённая насыщенность + один акцент; ★ «живость» неподвижной картинки —
  турбулентность на сниженной частоте кадров (у нас «кипение» уже есть); зум в начале у всех крупных; каждый элемент со звуком.
- Обложка: 3–5 слов + лицо/эмоция или символ; проверка в скрине ленты.
- ★ Визуальный хук без звука: текст выпрыгивает при загрузке; странное сочетание предметов («игла на фоне Земли»); резкие
  склейки; крик/люди в беде; красные круги, стрелки, отъезд/наезд/вбок на старте. Настоящий голос лучше ИИ.
- ★ Камера без остановок: следующее движение до конца предыдущего; склейка в высшей точке скорости; переход через предмет;
  раскрытие кругом-маской; слова по одному синхронно.
- Текст: по словам; одно слово — вторичная анимация (наклон, градиент); ★ печатная машинка: СТИРАНИЕ И ЗАМЕНА СЛОВА (у нас —
  «длинное извинение стирается → „Прости, долго“» — подтверждено источником c-Q06JnT6mE); «дрожащий» текст как стоп-моушен.
- Ключевое рукописным; 10 знаков в строке; J-cut 3–4 кадра.
- Одна фраза — одна картинка; «застрял — визуализируй одно слово»; не повторять один приём подряд; 10% стока.
- Глаза на одной линии через склейку; смена музыки на новой мысли; ложная ручная тряска.
- Звук: «без звука зритель дорисовывает»; короткие свисты — быстрые появления, хлыст — быстрые переходы, длинные — зумы; бумага/
  маркер/карандаш — «текст написан на бумаге»; «тишина может сказать больше 1000 звуков»; не обманывать звуком (слишком динамичный
  звук к обычному — почувствуют фальшь).
- ★ «Эмоциональный реализм» (Эйфория): звук того, что персонаж ЧУВСТВУЕТ (зёрна кофе — треск айсбергов) ⇒ письмо падает на стол

- 2D-объяснялки «близки благодаря персонажам»; рисованная доска «легко понять сложное»; лицо/персонаж сам становится хуком.
- Смэш-кат со звуком, который тоже обрывается; обратный порядок крупностей (с крупного — общий в конце: «оказывается, в пустыне»);
  матч-кат как метафора; фокус в той же точке — склейка невидима.
- Убрать звук прямо перед фразой; низкочастотный фильтр — «мир затаил дыхание».
- Текст: слово и картинка совпадают (в «деньги» — текстура купюры); текст за фигурой; без теней (дешевит); «слово на бумажке» для акцента.
- «Когнитивное прерывание» — ошибка в слове/странный шрифт. Визуальная одинаковость серии — безопасность. Без «философских роботов-голосов».
- §15.2: визуальный хук 5 категорий, «двинь тело, картинку или текст»; минимальный порог 2026; чёрные полосы смыкаются; белая
  обводка вокруг героя; первый кадр не предсказуем; странное действие; «рвёт лист — видео стартует с удара»; наезд в первом кадре.
  Своя палитра; «замените съёмку анимацией — перестаёте быть товаром»; цветокоррекция останавливает.
- Первый кадр не выдаёт ответ (черника). Один образ — одна идея; «каждое смысловое слово — свой кадр» («secret» — конверт, из
  которого выходит бумага); метафора фразы картинкой в момент слова.
- 9:16: один объект над другим; фокус в одном месте экрана; подсветка главного, остальное в серый; тень под элементом; ease-out.
- ★ Узнаваемость серии: одинаково выровненный первый кадр; «знали, что это твоё, ещё до имени — три цвета, два формата, одна мысль»;
  фактура бумаги как настоящая книга; символ; «меня запоминали по шрифту». Лицо/персонаж.
- В хуке один текст для чтения; хук-текст — отдельная красивая анимация («половина впечатления»).
- Не делать «СДВГ-субтитры» (скачут, меняют цвет) — утомляют; хайлайты вместо слово-в-слово; текст внутри сцены (листок, ладонь, экран).
- Нормы 17 зн/с; ≤3 слов; предлоги не в конце; выделить одно слово, ради которого смотрят.
- Безопасные зоны: верх ~250, низ 350–400, справа ~150.
- Звук для немого — главный носитель эмоции: свист → текстура → эмоция; riser когда вот-вот ценное, удар — на нём; «Я ещё не раскрыл
  риск — поэтому riser… boom на раскрытии»; пауза ~1 с с приглушением перед раскрытием; ТИКАНЬЕ И СЕРДЦЕБИЕНИЕ перед развязкой;
  на провале — грусть или без звука. Riser перед смэш-катом в тишину. Звук говорит невидимое (гулкий удар коробки = последствия).
  Звук-реакция: сверчки после «ты серьёзно?». Звук рвущейся бумаги — «наклоняется расслышать».
- Мера: если всё особенное — ничего; клавиша на каждую букву — ошибка (⇒ наш набор: не каждая буква одинаково!). Тишина 1–2 раза.
  Один постоянный набор звуков — ощущение серии.
- Монтаж: ≤2 ключевых точки на план, между ними ≥1 с; переходы — направление, не украшение; каждая фраза — 3–4 кадра; передышка
  после экшена. Счётчик набегает на экране.
