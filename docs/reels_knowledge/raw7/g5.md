### 2. Сценарий и структура 15–60 с
- **Интро из 5 шагов:** ожидание → контекст (почему важно) → любопытство (вопрос без ответа) → отличие (почему ты) → звук; шаги 2–4 в любом порядке, не все обязательны; естественная история, не шаблон. [кейс-разборы] — TQ7kuoNcni0
- **Контекст одной фразой** из выписанных проблем ЦА («студент сталкивается с отвлечениями, прокрастинацией, шумом»); не перегружать контекстом. — TQ7kuoNcni0
- **Формула истории Хормози:** персонаж → неудовлетворённое желание → препятствие → проводник с решением → план → пробует → работает → внутреннее достижение (кем стал) + внешнее (что изменилось). — LrjXV-rx1wE
- **Объяснение через аналогию**: связать известное с неизвестным («тело — машина, еда — бензин»); жаргон отталкивает. — LrjXV-rx1wE
- **Эскалация по шкале** (шкала ураганов, категории 1→5, «самое вредное — в конце»). — p6aF5ma7BiM
- **Смысл/история предмета делает его ценным:** кинцуги, Birkin, микрофон Элвиса, палки с Килиманджаро, доллар с автографом. — EM_kYc3jJtc, p6aF5ma7BiM
- **«Одно описательное слово»** меняет восприятие (не «вода», а «горная вода из Австрийских Альп»). — p6aF5ma7BiM

### 3. Удержание в середине: петли, паттерн-интерапты, темп, эскалация

### 16. Психология убеждения: триггеры, этично или нет, риски
- **Тест этики:** манипуляция — ради своей выгоды без согласия; обучение — ради выгоды зрителя с согласием. Магия допустима, пока зритель «в курсе». — p6aF5ma7BiM
- **Шкала BS (по нарастанию вреда):** маркировка (этично, защищает покупателя) → визуальная стенография (честно, если подчёркивает реальное свойство; фальшивый динамик — обман) → взаимность (слегка манипулятивно) → соцдоказательство (фейковые отзывы — обман) → авторитет («аура авторитета», Vicks, Camel — опасно) → дефицит (искусственный — FOMO, «жадность») → единство/племя (самое сильное и вредное — «культ»). — p6aF5ma7BiM
- **Шесть принципов Чалдини в продажах** с правилом «дефицит только настоящий — фальшивый «закрываю завтра» каждый день убивает доверие». — UtM_j0Pjxag
- **Последовательность «маленькие да»** — граница манипуляции. — UtM_j0Pjxag
- **Похожие люди в соцдоказательстве** сильнее (реклама FTX: повар, хирург, сантехник); нарочито домашняя съёмка звезды (Селена Гомес) — скепсис к «неотрепетированным» отзывам. — p6aF5ma7BiM
- **Проверка авторитета:** правда ли эксперт в этой области? что он выигрывает? — p6aF5ma7BiM
- **Честность заявлений снижает «BS»** (Liquid Death: дерзко, но правда). — p6aF5ma7BiM
- **Искусственная потребность, «ключ к лучшему я»** — манипуляция. — Dqk_-b8V8W0
