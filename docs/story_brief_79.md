# Рилс 79 «Месть сну» — общее задание агентам (автономно, БЕЗ генерации картинок, только код)

Тема (вид **Н**; голос **Daniel**; призыв **«Телеграм»** — `cta: "tg"`, решение владельца 16.11): Дима лёг в одиннадцать, а уснул в
три, хотя спать хотел уже в десять. Куда делась ночь? Весь день он жил для работы и для других, ни минуты для себя, поэтому ночью
мозг отбирает своё время у сна. Учёные в Голландии (Kroese и др. 2014, Утрехт) назвали это «откладыванием сна». Теперь Дима берёт
полчаса вечером для себя — гитара — и засыпает в одиннадцать, как кот.
Ход картинок: мансарда, часы без цифр крутятся, луна ныряет и солнце выскакивает в люке («Куда делась ночь?») → стрелки встают на
«три», телефон падает → вечер: зевок у раковины → кухня, клюёт носом, за окном луна встаёт → **карточка Телеграма** → фасад дома,
окна загораются, камера к мансарде → кот, звёзды стекают в телефон, люк пустой → день: солнце несётся по дуге → папки и чужие
просьбы → пыльная гитара, Дима пробегает мимо → рука отклеивает тёплый сектор «11–3» с циферблата → обнимает его, луна тянет
обратно, «хоть так» → вечерний Утрехт, канал, башня Дом, учёные с пиктограммой → палец отодвигает подушку-сон по полке → телефон в
ящик, гитара со стены → играет на коврике → гитару на стену, лампу гасит → **петля**: тот же ракурс, часы спокойно на 23:00, Дима
спит, кот клубком.
Папка: `videos/79_mest_snu/story/` (`script.txt`, `reel.json`, `voice/*` НЕ менять; `shots.json` — 18 планов, у каждого `group`
и `cut_anchor`; `sound.json` — 30 звуков, 10 разных, конец 32.4 с, голос до 32.08). `common/` скопирован из 78 (там есть
`hand_text.py`). Формат, стиль, Дима и кот — как в `docs/story_brief_78.md` и `docs/STORY_FORMAT.md`.

кухня с ужином и луной над крышами; фасад дома с окнами-историями; звёзды, стекающие в свет экрана; солнце по дуге над офисом и

**Не брать из 64, 70–78:** помидорку, песочные часы, колокольчик-таймер, кухонный таймер; качели, гору, ступеньку, кокон, палатки,
меловую стену, моторчик, башню листов, глыбу льда, костёр, мешок, кресло-мешок, мозг в любом виде (шарик, малыш, клубок, контур
