# Рилс эп.01 «3 дня. Одно письмо» — v1 (23.10), разбор по фразам

Первый рилс фабрики на другой теме после эталона v15 (эп.02). Цель — проверить, что новый агент по плейбуку и уроку
доводит рилс до уровня эталона, не повторяя его. Статус: кандидат, ждёт владельца. Немой (озвучки нет).

**Цель зрителя** (паспорт): «почему я третий день не могу сделать дело на пять минут?» → узнал себя → смешок над
собой с телефоном → облегчение: достаточно только открыть.

**Чем отличается от эталона (против шаблона):** хук-число («3 дня») вместо диссонанса «Ты не…»; два своих рисунка
рилса под фразы, где у эпизода картинки не было (кот с телефоном и забытым письмом, кот с песочными часами,
`gen/`, 281 250 баланса); авторитет — Уильям Додсон (психиатр, «нервная система, работающая на интересе»), а не Баркли;
нет часов хука, прожектора, красного круга, второго riser.

## v4 (24.10) — стандарт 10: хук из внутренних деталей, все 521 пункт матрицы решены

**Отбор хука — панель «зрителей»** (симуляция: шесть сегментов аудитории — школа, студенты, работающие, мамы, 40+,
