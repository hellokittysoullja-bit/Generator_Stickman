# Рилс 55 «начни» — общее задание агентам (автономно, БЕЗ генерации картинок, только код)

Тема (вид Н, наука, женский голос Alisa; карточки подписки нет, призыв «Напиши кот…» в последней строке): Дима неделю не может
сесть за отчёт → кажется, начинать надо сразу весь → кот: «Знаешь, почему начатое дело потом само тянет закончить?» →
незаконченное застревает в голове → Блюма Зейгарник заметила, что официанты помнят только неоплаченные заказы → начатое
помнится лучше, мозг хочет его закрыть → Дима садится на пять минут и пишет первую строчку → через пять минут вставать не
хочется, кот засыпает рядом → «Напиши кот, если тебе тоже трудно только начать».
Папка: `videos/55_nachni/story/` (`script.txt`, `voice/words.json`, `shots.json` — 18 планов, `sound.json` — 24 звука, конец 42.9 с).
Формат, стиль, Дима и кот — как в `docs/story_brief_29.md` и `docs/story_brief_51.md` (читать целиком).

## Контракт клипа
`clips/<id>.mp4` (в git не идёт): 1080×1920, 30 к/с, H.264 CRF 16, yuv420p, без звука, без субтитров. Клип покрывает время ролика
от max(0, t0 − 0.2) до t1 + 0.2 (кадр k = max(0, t0 − 0.2) + k/30; s18 — до 42.9+). Анимация от общего времени ролика, удары на
словах по `voice/words.json` (индексы слов в `sound.json`). Низ 1300–1560 — под субтитры: главное действие выше. Каждый план
двигается с первого кадра (камера и сам рисунок). Печатных надписей на рилс не больше одной: только рукописное «кот» на s17,
остальное штрихи-заглушки; мелкого текста на экранах нет. Дима — горчичное худи, лохматый, щетина, мешки под глазами; кот — `look/hero.png`
(ЛЕВОЕ от зрителя ухо загнуто, огонёк на кончике хвоста). Без двойных контуров, полупрозрачных фигур, кривых рук; лист кадров
глазами для каждого клипа, код сохранять в репозиторий сразу.
