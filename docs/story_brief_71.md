# Рилс 71 «два лагеря» — общее задание агентам (автономно, БЕЗ генерации картинок, только код)

Тема (вид **Х** — история-комедия, без исследования и учёных; молодой мужской голос Evgeniy, `"voice": "male2"`, динамичное начало):
«Люди без СДВГ, объясните: как вы просто встаёте и делаете?» → Дима правда не понимает, в комментариях спорят два лагеря → одни:
«просто встаёшь и делаешь, что тут сложного» → другие: «я тоже так не могу, и дело не в лени» → друг честно говорит, что даже не
думает об этом, просто встаёт → а Дима перед каждым делом будто стоит у стены, которую никто, кроме него, не видит → его способ:
первый шаг такой маленький, что стена его не замечает → открыть ноутбук, надеть один носок, налить воды, а дальше идёт само, кот
смотрит одобрительно → «Напиши, из какого ты лагеря и что помогает тебе встать и сделать».
Папка: `videos/71_dva_lagerya/story/` (`script.txt`, `reel.json`, `voice/*` не менять; `shots.json` — 22 плана, у каждого поле `group`,
`sound.json` — 48 звуков, конец 38.2 с, голос до 37.92). Формат, стиль, Дима и кот — как в `docs/story_brief_70.md` (вид Х того же
устройства), `64`, `62`. Свежий код — рилс 70 (`videos/70_pomidorka/story/common/*`, `ext_*`), 64, 63.
**Тон:** без стыда и без «войны лагерей»: оба лагеря — пузыри и палатки, людей не высмеиваем; друг не злодей, он просто так устроен;
стена — не «лень», а невидимая преграда, и решение — маленький шаг, а не сила воли. Комедия — темп и мимика, 1–2,6 с на план.
**Главные образы рилса (новые, не повторять прошлые):** Дима в одеяле-коконе (хук и петля), друг-«тост» выстреливает из кровати,
два лагеря — две туристические палатки на бумаге (жёлтая с флажком-молнией, синяя с флажком-клубком; не одеяльная палатка 60),
пузыри-реплики без букв, невидимая стена как у мима (пунктирный меловой контур только там, где ладони), стена-сторож с сонными
глазами, ящик-дело сжимается щепотью в кубик, три маленьких шага: ноутбук, один полосатый носок, стакан воды.
**Не брать из 64 и 70:** таймер-помидорку и любые таймеры, качели, гору, ступеньку, пьедестал, кляксу, стену «через плечо».

## Контракт клипа
`clips/<id>.mp4` (в git не идёт): 1080×1920, 30 к/с, H.264 CRF 16, yuv420p, без звука, без субтитров. Длина (t1 − t0) + 0.4 с: клип
покрывает время ролика от max(0, t0 − 0.2) до t1 + 0.2 (кадр k = max(0, t0 − 0.2) + k/30; s01 начинается с 0, s22 — до 38.2 + 0.2
можно, сборщик обрежет по `end`). Анимация от общего времени ролика, удары на словах по `voice/words.json` (секунды слов — в `what`
каждого плана в `shots.json`). Низ 1300–1560 под субтитры: главное действие выше. Каждый план двигается с первого кадра (камера и сам
рисунок). Рендер клипа — ОДИН процесс.
**Хук s01 (правила 25–29 CLAUDE.md):** в кадре 0 кокон УЖЕ катится к камере — несколько слоёв движутся одновременно (складки одеяла,
лицо, волосы, подушка, пылинки в полосе света); за первые 0.1 с меняется ≥ 12 % рисунка, в среднем ≥ 6.5 % на кадр первой секунды,
ни один кадр не < 3 % (ease без разгона с нуля, до удара — второй подскок кокона, а не плавное ожидание); влёт камеры 1/(1+0.4)→1
за 0.22 с с поворотом 3–4°, удар на ударном слоге «Лю» (0.30) — кокон плюхается на подушку, второй удар +8 % на «СДВГ» (0.95);
**рук в хуке нет**: после влёта ЛИЦО и КОКОН-одеяло вместе ≥ 65 % высоты картинки (лицо одно ≥ 35 %), без бумаги вокруг. Проверить
замером (`anim.opening_motion`-подобно, по кадрам клипа без камеры) и листом; числа — в отчёт группы C.
**Надписей нет вовсе**; единственная надпись рилса — рукописное «кот» на s21 модулем `common/hand_kot.py`, на чистой стене, за буквами
ни одного предмета (голос в призыве «кот» не говорит — это подпись бренда, как во всех рилсах формата 4). **Без букв и цифр нигде:**
пузыри — только штрихи-волны и пиктограммы (стрелка вверх, клубок); флажки палаток — знаки; клавиши пустые; экран ноутбука — свет и
волнистые строки штрихами; ящик без надписей. Взрослый Дима — горчичное худи, лохматый, щетина; друг — `friend` из `people.py`
(рыжий, другая кофта), один и тот же в s02, s09, s10. Без двойных контуров, полупрозрачных фигур, кривых рук; лист кадров глазами для
каждого клипа (`ffmpeg … fps=2,tile`), код и клипы сохранять сразу, пушить только свои файлы
(`git pull --rebase --autostash origin main && git push origin HEAD:main`; чужие `ext_*` и другие рилсы не трогать).

## Промахи рилсов 55–70, которые нельзя повторить
- **Рукава-трубы (70):** на крупных планах рукав худи был толще предплечья. Здесь **макро предплечий нет нигде**: руки — только в

- **Ноутбук к зрителю (70):** экран ВСЕГДА повёрнут к Диме; свет экрана — на его лице.
- **Хват пальцами:** пальцы огибают графин, кружку, крышку; большой палец виден; не предмет, «приклеенный» к кулаку.
- **Дима не мелкий:** на всех планах с ним ≥ 45 % высоты картинки (в коконе s01/s22 — лицо и кокон ≥ 65 %); один и тот же во всех
  группах. Друг — один и тот же.
- **Кот:** почти чёрный #2a2d30–#3b4143 как `look/hero.png` (проверить пикселем), ЛЕВОЕ ухо загнуто, оранжевое только огонёк на хвосте;
  не скользит — шагает (s12 сквозь стену — шагом); меняет позу через промежуточные кадры.
- **Невидимая стена — не полупрозрачная фигура:** только тонкий пунктирный меловой контур кирпичей, проявляется на 0.3–0.5 с у ладоней
  и гаснет; на s15 и s19 — та же стена как рисунок мелом.
- **Повороты не сжатием фигуры**, **свет без огромных мягких овалов** (утро — полоса формы окна), **«кот» только `hand_kot.py`**,
  **лица и позы разные**, не больше двух похожих планов подряд.
- Порядок: кокон катится на камеру → друг-тост → Дима не понимает → рой пузырей и два лагеря → жёлтый лагерь стреляет пузырём →
  пузыри бьют Диму в лоб → синий лагерь, пузыри в ряд → кокон сползает → кухня, вопрос другу → друг мгновенно встаёт → три дела, нос
  о стену → мим у стены, кот проходит насквозь → кот даёт носок, прищур → ящик в кубик → кубик и Дима под стеной-сторожем → ноутбук →
  носок → вода → поток, стена осыпается → кот одобряет → призыв, флажки, «кот» → петля к кокону, Дима выпрыгивает.
