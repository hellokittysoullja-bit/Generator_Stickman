# Формат 4: рилс-история 9:16, нарисованный кодом (Дима + кот)

Владелец 12–13.11: «люди герои, кот дополнительно», «кодом нарисовать, а не генерация», «время рендера не важно,
главное качество», «без артефактов». Образцы: `videos/23_vybor`, `24_finish`, `25_noch_dela`, `26_krossovki`
(папка `story/`). Очередь следующих — `docs/story_queue.md`. Платное — только голос Lumean (дёшево); генерации картинок нет.

## Порядок одного рилса (≈1–1,5 ч)
1. Тема из очереди → `videos/NN_имя/story/script.txt` (9 строк, ~35 с, до 600 знаков). Скелет:
   (для вида Н; виды Х и М — в `docs/story_queue.md`) 1) хук-боль Димы с ударом с 0 с, 2) усиление, 3) кот: «Знаешь, почему…?», 4) механизм простыми словами,
   5–6) исследование (только факт из очереди, место словами «в Британии», «в Стэнфорде»), 7) что Дима делает теперь,
   8) итог, кот рядом, 9) «Напиши кот, если…». Человеческий текст: без тире, без «не просто X, а Y», «ты».
2. `reel.json` (beats; `[energetic]` на 0-й строке, `[short pause]` на 2-й) → `python scripts/reel_voice.py videos/NN/story`
   → `voice/words.json`.
3. `shots.json` (14–18 планов по 1,3–3 с, первый ≤ 1,5 с, движение с кадра 0, `whip` на смене места, сцены
   room / 2D), `sound.json` (только звуки из `reel.SFX_LIB`, пик на событии: склейка или слово, 15–25 штук),
   `.gitignore` с `room/chars/*/L_*/` и `clips/`.
4. Задание агентам — копия `docs/story_brief_26.md` с новой темой; 3 агента параллельно: room (Blender-проходы
   `scratchpad/blender/p24all` + SVG-герои, основа `videos/26_krossovki/story/room/`), 2D-A и 2D-B
   (основа `videos/26_krossovki/story/ext_a`, `ext_b`, бег — `run/`). Каждый проверяет листы глазами.
5. `python scripts/story_reel.py videos/NN/story` → лист кадров `fps=1,tile` глазами, громкость (−18…−15 LUFS,
   пик < −1 дБ) → коммит `reel.mp4` и исходников (клипы НЕ в git) → push → отправить владельцу с честными недостатками.
6. Удалить `clips/*.mp4` локально (диск), статус в очереди.

## Если диск или лимит
- Диск < 1 ГБ: удалить `clips/` готовых рилсов, листы в scratchpad. Blender (`scratchpad/blender/blender-4.2.3…`) и
  `p24all`, `p23`, `p24room` не трогать — без них комнату не собрать. Нет scratchpad (новая сессия) — проходы
  пересчитать `videos/23_vybor/story/room/passes.py` (~30 мин) или делать рилс без Blender, целиком 2D.
- Лимит API у агентов: дождаться сброса и продолжить их (SendMessage), не начинать заново.
