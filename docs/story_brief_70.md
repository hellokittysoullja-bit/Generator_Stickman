# Рилс 70 «помидорка» — общее задание агентам (автономно, БЕЗ генерации картинок, только код)

Тема (вид **Х** — история с поворотом, без исследования; молодой мужской голос Evgeniy, `"voice": "male2"`; призыв «Напиши кот…»
в последней строке):
«Помидорка на двадцать пять минут худший совет для того, кто не может начать» → Дима поставил таймер, сел и двадцать пять минут
смотрел в стену → ещё раз, и ещё, и решил, что с ним что-то не так → а дело совсем не в нём → двадцать пять минут звучат как гора,
когда даже первая минута кажется невозможной → таймер помогает тому, кто уже начал, а не тому, кто стоит у двери → теперь Дима ставит
таймер на две минуты и просто открывает файл → через две минуты он уже пишет, останавливаться не хочется, кот спит рядом →
«Напиши кот, если помидорка тебе тоже не помогает».
Папка: `videos/70_pomidorka/story/` (`script.txt`, `reel.json`, `voice/*` не менять; `shots.json` — 18 планов, у каждого поле `group`,
`sound.json` — 31 звук, конец 34.9 с, голос до 34.64). Формат, стиль, Дима и кот — как в `docs/story_brief_64.md`, `63`, `62` (вид Х
того же устройства — `62`). Свежий код — рилс 64 (`videos/64_spasibo/story/common/*`, `ext_*`), 63, 61.
**Тон:** без стыда — Дима не «ленивый», ему мешает слишком большой первый шаг; поворот «дело не в нём» снимает вину. Правда — простыми
картинками: гора, ступенька-стена, качели, дверь.
**Главный предмет рилса — красный кухонный таймер-помидорка** с зелёным листиком-хвостиком (новый предмет: в прошлых рилсах был
таймер-яйцо и таймеры с цифрами — их НЕ повторять). Шкала — только риски, **без цифр**; заведённое время — красный клин-сектор на белом
циферблате: «25 минут» — почти полкруга, «две минуты» — тонкий ломтик. Таймер один и тот же во всех планах (`props.tomato_timer`).

## Контракт клипа
`clips/<id>.mp4` (в git не идёт): 1080×1920, 30 к/с, H.264 CRF 16, yuv420p, без звука, без субтитров. Длина (t1 − t0) + 0.4 с: клип
покрывает время ролика от max(0, t0 − 0.2) до t1 + 0.2 (кадр k = max(0, t0 − 0.2) + k/30; s01 начинается с 0, s18 — до 34.9 + 0.2
можно, сборщик обрежет по `end`). Анимация от общего времени ролика, удары на словах по `voice/words.json` (секунды слов — в `what`
каждого плана в `shots.json`). Низ 1300–1560 под субтитры: главное действие выше. Каждый план двигается с первого кадра (камера и сам
рисунок). Рендер клипа — ОДИН процесс.
**Хук s01 (правила 25–29 CLAUDE.md):** в кадре 0 таймер уже крутится в пальцах, несколько слоёв движутся одновременно (пальцы, клин,
листик, лицо); за первые 0.1 с меняется ≥ 12 % рисунка, ни один кадр первой секунды не стоит (< 3 %); влёт камеры 1/(1+0.4)→1 за
0.22 с с поворотом 3–4°, удар на ударном слоге «Помидорка» (0.30), второй удар +8 % на «двадцать» (0.61); после влёта таймер, рука и
лицо Димы занимают ≥ 65 % высоты картинки.
**Надписей нет вовсе**; единственная надпись рилса — рукописное «кот» на s17 модулем `common/hand_kot.py`, на чистой стене, за буквами
ни одного предмета. **Без букв и цифр нигде:** циферблат таймера — риски и клин; клавиши ноутбука пустые; экран — белая страница с
чертой-курсором, потом волнистые строки штрихами; дверь без табличек. Взрослый Дима — горчичное худи, лохматый, щетина (ночью
s01–s08 лёгкие мешки под глазами, утром s13–s18 свежий). Без двойных контуров, полупрозрачных фигур, кривых рук; лист кадров глазами
для каждого клипа (`ffmpeg … fps=2,tile`), код и клипы сохранять сразу, пушить только свои файлы
(`git pull --rebase --autostash origin main && git push origin HEAD:main`; чужие `ext_*` и другие рилсы не трогать).

## Промахи рилсов 55–64, которые нельзя повторить
- **Хват пальцами:** пальцы огибают таймер, ручку двери, кружку; большой палец виден; не плоская ладонь и не предмет, «приклеенный» к
  кулаку. **Руки не палки:** локоть, плечо, пропорции; рукав худи не толще предплечья; кисть ≈ 1/3 лица.
- **Дима не мелкий:** на всех планах с ним взрослый Дима ≥ 45 % высоты картинки (на s03 — к концу лицо ≥ 50 %, на s06 — рука и рукав
  крупно); один и тот же во всех группах.
- **Кот:** почти чёрный #2a2d30–#3b4143 как `look/hero.png` (проверить пикселем), ЛЕВОЕ ухо загнуто, оранжевое только огонёк на хвосте;
  не скользит — шагает и запрыгивает с толчком (s08); меняет позу через промежуточные кадры.
- **Повороты не сжатием фигуры**, **свет без огромных мягких овалов** (лампа — небольшой круг с чёткой формой абажура; утро — полоса
  формы окна), **«кот» только `hand_kot.py`**, **лица и позы разные**, не больше двух похожих планов подряд.
- Сюжет не повторяет прошлые рилсы: таймер-помидорка (не яйцо, не цифры), стена через плечо, отражение в тёмном экране, гора из таймера,
  ступенька-стена, качели во дворе, дверь — новые события и ракурсы.
- Порядок: таймер крупно (ночь) → помидорка на пьедестале шлёпается → руки над клавиатурой → завёл таймер → смотрит в стену → звонок и
  перезавод → отражение, голова на руки → кот толкает таймер → гора → ступенька-стена → качели → дверь → утро, таймер в руке → тонкий
  клин, открыл файл → пишет → кот спит с таймером → призыв → петля к таймеру крупно.
