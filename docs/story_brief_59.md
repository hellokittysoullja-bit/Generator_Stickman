## Промахи рилсов 55–58, которые нельзя повторить
- **Руки не держат предметы:** хват пальцами, пальцы огибают предмет, большой палец виден (ноутбук, лист, букет, пирог, дверца духовки).
- **Огромные руки и рукава на крупных планах:** кисть ≈ 1/3 лица, рукав не толще предплечья; кисти на крупных планах рисовать отдельно.
- **Дима мелкий на общих планах:** на s01, s03, s09, s11, s14 фигура Димы не меньше ~45 % высоты картинки.
- **Кот не чёрный:** почти чёрный #2a2d30–#3b4143 как `look/hero.png`, ЛЕВОЕ ухо загнуто, оранжевое только огонёк на хвосте; дневной свет без коричневых тонировок; проверить цвет шерсти пикселем.
- **«кот» печатными буквами:** только живой рукой, штрихи разной толщины, буквы разной высоты, строка с наклоном.
- **Одинаковые фигуры с пустыми лицами:** у Димы своя мимика на каждом плане (азарт, ступор, растерянность, паника, гордость, радость); три друга и продавщица с разными лицами, ростом и одеждой; мама не копия Димы; кот с реакцией, не иконка.
- Не больше двух похожих планов подряд: чередовать масштаб (комната общий → коробка крупно → комната → экран крупно → друзья средний → лист крупно → голова → корзина → календарь → ларёк → кухня → мама → стол → финал).
