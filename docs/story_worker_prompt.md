их папки не трогай, при конфликте push делай `git pull --rebase` и снова push.

Прочитай первым делом: CLAUDE.md (первый раздел), docs/STORY_FORMAT.md, docs/story_queue.md (твоя строка: вид Н/Х/М/П,

videos/NN_xxx/story/{script.txt,reel.json,voice/words.json} — сценарий и голос УЖЕ готовы, их не меняй. Если есть
videos/NN_xxx/story/publish_notes.md — там раскадровка владельца, ей следовать.

0) Если нет shots.json и sound.json — написать их по голосу (words.json), по образцу videos/29_uborka/story/: 13–18
   планов по 1,3–3 с, первый ≤ 1,5 с с влётом камеры и движением с кадра 0, whip на смене места, звуки только из
   reel.SFX_LIB (проверить импортом scripts/reel.py), пик на событии; призыв подписаться — карточка с колокольчиком и
