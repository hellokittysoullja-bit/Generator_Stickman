# Рилс 61 «стол» — общее задание агентам (автономно, БЕЗ генерации картинок, только код)

Тема (вид Н, исследование, женский голос Alisa; карточки подписки нет, призыв «Напиши кот…» в последней строке): у Димы на столе
бумажки, кружки, провода → мама: «в таком бардаке ничего хорошего не придумаешь» → кот: «Знаешь, может ли беспорядок вообще
помогать?» → обстановка подталкивает мозг думать по-разному → в Миннесоте людей сажали в аккуратную или захламлённую комнату и
просили придумать идеи (Vohs, Redden, Rahinel 2013, Университет Миннесоты) → в беспорядке идеи необычнее, в порядке чаще выбирали
полезную еду (яблоко, а не шоколадку) и привычное → теперь Дима придумывает за творческим столом, а дела по плану — за чистым → два
стола, никакого стыда, кот спит на том, где теплее → «Напиши кот, если у тебя тоже творческий бардак».
Папка: `videos/61_stol/story/` (`script.txt`, `voice/words.json` не менять; `shots.json` — 18 планов, `sound.json` — 25 звуков,
конец 47.5 с). Формат, стиль, Дима и кот — как в `docs/story_brief_60.md` и `55`–`59` (свежий образец — `60`).

## Контракт клипа
`clips/<id>.mp4` (в git не идёт): 1080×1920, 30 к/с, H.264 CRF 16, yuv420p, без звука, без субтитров. Клип покрывает время ролика от
max(0, t0 − 0.2) до t1 + 0.2 (кадр k = max(0, t0 − 0.2) + k/30; s18 — до 47.5). Анимация от общего времени ролика, удары на словах по
`voice/words.json` (секунды слов — в `what` каждого плана). Низ 1300–1560 под субтитры: главное действие выше. Каждый план
двигается с первого кадра (камера и сам рисунок). Рендер клипа — ОДИН процесс. Печатных надписей нет вовсе; единственная надпись
рилса — рукописное «кот» на s18 модулем `common/hand_kot.py` (копия `videos/60_temnota/story/ext_f/hand_kot.py` — там впервые вышел
настоящий курсив; группа F копирует его в первые минуты). **Бумажки, листы, наброски, стикеры, чекбоксы — без букв и цифр**, только
штрихи и значки; мелкого текста нет нигде (экран ноутбука пустой или закрыт). Взрослый Дима — горчичное худи, лохматый, щетина,
мешки под глазами. Без двойных контуров, полупрозрачных фигур, кривых рук; лист кадров глазами для каждого клипа, код и клипы
сохранять и пушить сразу (`git pull --rebase --autostash origin main && git push origin HEAD:main`, только свои файлы).

## Промахи рилсов 55–60, которые нельзя повторить
- **Хват пальцами:** пальцы огибают предмет (кружка, маркер, яблоко, провод, поднос), большой палец виден, не плоская ладонь.
- **Руки не палки:** локоть и плечо, пропорции предплечья; **без гигантских рукавов** — рукав не толще предплечья; кисть ≈ 1/3 лица.
- **Дима не мелкий:** на s02, s14, s16, s18 фигура Димы ≥ 45 % высоты картинки, на общих планах тоже; не вечный присед.
- **Кот:** почти чёрный #2a2d30–#3b4143 как `look/hero.png` (проверить цвет шерсти пикселем), ЛЕВОЕ ухо загнуто, оранжевое только
  огонёк на хвосте; не скользит — шагает лапами и запрыгивает с толчком задних лап (s04), сворачивается клубком (s17).
- **Лица и позы разные:** у каждого плана своя мимика; мама не копия Димы; участники эксперимента не копии друг друга и Димы.
- **Световые пятна не огромными мягкими овалами:** тёплый свет лампы — небольшой круг на столе с чёткой формой абажура, не
  размытый эллипс на полкадра.
- **«кот» не печатными буквами:** только `hand_kot.py`, живое перо.
- Не больше двух похожих планов подряд: порядок мест — стол крупно → Дима за столом → мама в двери → Дима и кот → кот крупно →
  мозг → лампочки → аккуратная комната → захламлённая → два лица → облачка → участница → поднос → творческий стол → чистый стол →
  общий план → кот спит → призыв.
