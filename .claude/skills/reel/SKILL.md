# Рилс 9:16

Планка — рилс эп.02 (`videos/02_sdvg_vremya/reel/`, v10), который владелец назвал «намного лучше». Новый рилс
не хуже ни по одному пункту ниже.

1. **Прочитать `docs/REELS_PLAYBOOK.md` целиком** — там хук, звуки по смыслу, субтитры, раскладка, приёмка,
   решения владельца и откуда каждое правило. Раздел рилса в CLAUDE.md — история правок.
2. **Образец:** скопировать `videos/02_sdvg_vremya/reel/reel.json` в `videos/NN_тема/reel/reel.json`, источники
   (`sources`) — оплаченные кадры своего эпизода (`../frames/00N.png`). Новых платных картинок не заказывать.
3. **Сценарий:** первая фраза — когнитивный диссонанс по боли аудитории (СДВГ и люди без диагноза с теми же
   симптомами), ≤ 30 знаков; вторая — раскрытие на пике riser. Структура — в плейбуке. Фактчек имён и терминов.
4. **Окна и звуки — руками, по смыслу каждого слова.** Звук озвучивает событие или поворот смысла (`oof` на провале,
   `swoosh_deep` на появлении), не украшает склейку. Только 4 звука владельца, без музыки, без звуков на субтитрах.
5. `python scripts/reel_rules.py videos/NN_тема/reel` → `python scripts/reel.py videos/NN_тема/reel --sheet` (лист
   глазами) → `python scripts/reel.py videos/NN_тема/reel`. Правила кода не обходить: `--force` — только с причиной,
   названной владельцу.
6. **Приёмка:** кадры 0.0 / 1.0 / 1.65 / 2.5 с глазами; `python scripts/reel_metrics.py videos/02_sdvg_vremya/reel/reel.mp4
   videos/NN_тема/reel/reel.mp4` — не хуже эп.02 по неподвижным кадрам и резкости; скиллы `deep-audit` и
   `av-ground-truth-check` до слова «готово». Честно назвать, что не проверено (телефон, удержание).
7. Новое правило от владельца — сразу в плейбук (и в `reel_rules.py`, если его можно проверить кодом, с тестом в
   `tests/test_reel_rules.py`). Новые изученные ролики — в `docs/reels_sources.txt`.
