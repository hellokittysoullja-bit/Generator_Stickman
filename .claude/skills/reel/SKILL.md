# Рилс 9:16

Планка — **текущий эталон** из таблицы «Эталоны» плейбука (с 23.10 — рилс эп.02 `videos/02_sdvg_vremya/reel/`, v15, одобрен владельцем).
Эталон растёт: следующий одобренный владельцем рилс, который лучше, становится эталоном, старые остаются историей.
Новый рилс не хуже текущего эталона ни по одному пункту ниже.

1. **Обязательное чтение (порядок — в начале плейбука):** `docs/REELS_PLAYBOOK.md` целиком → `docs/REELS_LESSONS.md` (журнал ошибок: не повторять) → разбор текущего
   эталона `docs/reels_cases/` → план `docs/reels_knowledge/04_apply_to_our_reel.md` → тематические файлы базы по
   задаче (хук, воронка и аудитория — сначала `09_hooks_funnels_audience.md`, волна 9; затем `08_deep_persuasion_funnel.md`) → журнал `docs/reels_log.json`. Раздел рилса в CLAUDE.md — история правок.
   **Стандарт 9 (с 24.10):** `passport.standard: 9` и паспорт хука `passport.hook` (≥ 20 кандидатов из фраз аудитории,
   рычаг §10, обещание и выплата, первый кадр без решения), варианты хука с другим первым кадром, кодовое слово —
   проверяет `check_hook`; образец — эп.01 v3, тексты лички и бота — `docs/reels_funnel_texts.md`.
   **Не шаблонно:** другой тип хука, другие первые слова и не больше половины приёмов прошлого рилса — паспорт
   `passport` в reel.json, правило кода `check_passport` не даст повторить.
1а. **Хук двигается внутри рисунка (стандарт 14, с 25.10):** сцена `anim` по скиллу `reel-anim` — его открыть до
   первой строки сцены; там образцы, помощники и ошибки, которые уже стоили времени. Якорь 2–4 слова, голос и удар с
   0 с, повторный хук до 4.2 с — проверяет `check_hook_motion`.
2. **Черновик программой:** сценарий в `videos/NN_тема/reel/reel_script.txt` (фраза в строке, `*ключевое*`, `@f3` —
   кадр эпизода) → `python scripts/reel_draft.py videos/NN_тема/reel` собирает reel.json по правилам. Образец ручной
   доводки — reel.json текущего эталона. Новых платных картинок без слова владельца не заказывать; по его слову — `scripts/reel_draw.py` (плейбук, «Кто что делает»).
2а. **Знания базы — в каждой фразе:** заполнить `passport.knowledge` по `docs/reels_knowledge/apply_checklist.json`
   (номер фразы или `{"skip": "причина"}`), плюс `labels`, `cover`, `caption`, `hook_variants`, `cta_beat`. Пока есть
   `TODO`, reel.py не рендерит. Как сделать каждый пункт — смотреть источник пункта в базе (07 §8 — маркетинг, воронка,
   бренд; 01 — хук и удержание; 06 — данные платформ), тёмные паттерны (07 §Г) — никогда.
3. **Сценарий:** первая фраза — когнитивный диссонанс по боли аудитории (СДВГ и люди без диагноза с теми же
   симптомами), ≤ 30 знаков; вторая — раскрытие на пике riser. Структура — в плейбуке. Фактчек имён и терминов.
3а. **Хук ворует внимание (владелец 25.10, обязательно для всех агентов):** визуал + вербал + невербал (мимика, поза, тон) + движение или необычный ракурс, и не один эффект: в первой фразе ≥ 2 визуальных эффекта сразу и звук с 0 с. `passport.hook.steal`, `check_hook_steal`, стандарт 13.
4. **Окна и звуки — руками, по смыслу каждого слова.** Звук озвучивает событие или поворот смысла (`oof` на провале,
   `swoosh_deep` на появлении), не украшает склейку. Звуки — только из библиотеки `assets/sfx/reels/library.json` (там написано, что каждый значит и когда его ставить), без музыки, без звуков на субтитрах.
4а. **Монтаж как у образца эп.02 v9 (владелец 25.10):** кукла — только с 72 % ролика (финал), середина — рисунки; рисунков ≥ 6, и хотя бы один нарисован для этого рилса (`reel_draw.py`, на один больше образца); акцентов ≥ 4 на 10 с, ≥ 5 видов (прожектор-затемнение, круг, удар-наезд, тряска, вход наездом, пометка, стрелка, хлёст) — каждый на смысловом слове. `check_montage`, стандарт 14. Затемнение — только на ключевом слове и не чаще раза в 5 с (`check_spots`); свисты не ближе 1.5 с (`check_whoosh_gap`, владелец 26.10).
5. `python scripts/reel_rules.py videos/NN_тема/reel` → `python scripts/reel.py videos/NN_тема/reel --sheet` (лист
   глазами; **рендер только при нуле ✗** — там же геометрия: обрывки, кукла, надписи) → `python scripts/reel.py videos/NN_тема/reel`. Правила кода не обходить: `--force` — только с причиной,
   названной владельцу.
6. **Комплект публикации** (`publish.md`, `cover.jpg`) reel.py собирает сам — проверить глазами обложку и подпись; варианты хука для пробных Reels — `python scripts/reel_variant.py videos/NN_тема/reel --hook "…"`.
6б. **Владельцу на просмотр** — `python scripts/reel_review.py videos/NN_тема/reel` → `review.html` с кнопкой «Отметить» (заметки с временем копируются одной кнопкой).
6а. **Приёмка:** лист проверки `proof.jpg` (reel.py делает сам, одна картинка на весь рилс) глазами; `python scripts/reel_metrics.py <эталон>/reel.mp4
   videos/NN_тема/reel/reel.mp4` — не хуже эталона по неподвижным кадрам и резкости; скиллы `deep-audit` и
   `av-ground-truth-check` до слова «готово». Честно назвать, что не проверено (телефон, удержание).
7. После рилса: паспорт — в `docs/reels_log.json`, разбор по фразам — в `docs/reels_cases/`. Новое правило от владельца — сразу в плейбук (и в `reel_rules.py`, если его можно проверить кодом, с тестом в
   `tests/test_reel_rules.py`). Новые изученные ролики — в `docs/reels_sources.txt`.
