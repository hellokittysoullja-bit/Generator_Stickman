# Движение внутри рисунка (одобрено владельцем 25.10)

## Принцип начала рилса (владелец 26.10: «понравилось, особенно первый; записать, чтобы следующие сессии сразу так делали»)
Первые 2 секунды никогда не стоят и не звучат одним звуком. Не шаблон и не обязательный порядок эффектов, а принцип:
1. **Рисунок двигается сам, качественно** (сцена `anim`, скилл `reel-anim`): событие боли происходит у зрителя на
   глазах — предмет падает, руки тычут, телефон выскальзывает. Не только камера и не «резиновое» растягивание:
   слой, замах, удар на ударной гласной, задержка 2 кадра, отскок пружиной, детали состояния (мешки, пыль).
2. **Несколько звуков, каждый на своё событие** (только звуки владельца, по смыслу): удар с 0 с (`fast_whoosh`) под
   резкий наезд, `riser` с 0 с к раскрытию, звук на само событие рисунка (`oof` на шлепок, на последний тычок).
   В «ленивом» звуки идут на каждый тычок рук — так и надо: звук озвучивает движение, а не украшает склейку.
3. **Камера отвечает на событие:** резкий наезд с первого кадра, вздрагивание и тряска на ударе.
4. **Текст движется с речью:** якорь от руки 2–4 слова и субтитры по словам с 0 с.
Набор и порядок — свои в каждом рилсе (против шаблона, `check_passport`); неизменно одно: с первого кадра что-то
происходит в самом рисунке и это слышно больше чем одним звуком. Код проверяет сцену, якорь, удар и riser с 0 с
(стандарт 14), качество движения — лист `anim.sheet` и покадровый просмотр удара перед рендером.


Образцы — три готовые сцены, копировать ближайшую, а не писать с нуля:

| сцена | что | на чём держится |
|---|---|---|
| `videos/03_lenivyi/reel/anim/hands_poke.py` | три руки влетают и тычут в кота по слогам | **один рисунок на бумаге**: предметы вырезаются сами (`ink_objects`) |
| `videos/05_ustal/reel/anim/envelope_fall.py` | тень растёт, конверт падает на спину, пыль | **рисунок А + рисунок Б** (после удара), предмет вырезан с Б |
| `videos/04_noch/reel/anim/phone_fall.py` | телефон выскальзывает из лап, падает на морду, уносит свет | **тёмный фон**: фон под предметом восстановлен, свет экрана едет с телефоном |

## Порядок (каждый шаг — одна команда, проверка — лист, а не рендер)

1. **Выбрать тип.** Предмет отдельно на бумаге → как `hands_poke` (без ручной разметки). Нужен «после удара» другой
   рисунок (поза, лицо) → А + Б: Б генерировать **по А как сцене** (`python scripts/reel_pose_b.py videos/NN/reel`, задания в `reel/pose_b.json` — тот же
   рисунок, сдвиг ≤ 2 px; проверить `cv2.phaseCorrelate`). Новые платные рисунки — только со слова владельца.
2. **Координаты — сеткой, а не на глаз:** `anim.grid(img_x2, (x0, y0, x1, y1), path, zoom=1..3)` — подписи сетки в
   координатах рисунка ×2, переписывать числа прямо. Все координаты сцены — ×2 (исходники рилса увеличены вдвое).
3. **Слои:**
   - на бумаге — `anim.ink_objects(img, box)` (фон = самый большой кусок бумаги, блики не дырявят маску);
   - по грубому многоугольнику — `anim.cut_polygon(img, poly)` (GrabCut, контур тушью остаётся предмету);
   - фон под предметом — `anim.fill_hole(img, hole, grain_from=...)`; бумага рилса — `anim.paper_like(img)`;
   - спрятанная часть предмета (за шерстью, за пальцами) — достроить бумагой/корпусом вдоль оси и контуром тушью;
     шерсть отличать от туши по яркости (тушь L < 40, шерсть 40–120), а лучше — узкой ручной полосой у края.
   Всё — в `prepare()` с кэшем `reel/.cache/anim/<сцена>_v<VERSION>.npz`; правка подготовки = `VERSION += 1`.
4. **Хронометраж по голосу:** `ctx["words"]` — [(start, end)] слов фразы; удар — на ударную гласную
   (`start + 0.07…0.15`). Голос с 0 с, удар звука `fast_whoosh` на 0, `oof`/`shock` — на удар.
5. **Движение — по правилам анимации:**
   - замах перед действием (0.10 с назад), действие, задержка на ударе **2 кадра**, отскок пружиной (`anim.spring`);
   - падение — `anim.gravity` (путь ∝ t²); вход — `anim.SNAP`; торможение — `anim.EASE_OUT`;
   - **рисованное на двойках** (`anim.on_twos`), быстрое (падение, тычок, первый отскок) — на единицах, камера — 30;
   - предмет — слоем (`Layer.draw`: поворот, сжатие вдоль оси); фон не растягивать;
   - смаз — только у слоя (`smear=(vx, vy)` в px за кадр), он ложится позади;
   - смена А → Б — **в кадр удара** (вспышка / пыль / тряска закрывают смену);
   - персонаж на ударе — `anim.squash_follow(img, mask, (cx, пол), amount, t, lag=0.12, focus=точка_удара,
     rigid=[маски твёрдого])`: объём держится, место удара отвечает в тот же кадр, хвост и дальнее ухо догоняют,
     телефон или конверт на персонаже не гнутся. `amount(t)` — функция (пружина), а не число: ей нужны прошлые моменты.
     `squash_region` — только для дыхания (мелкое, одним полем);
   - штрихи удара — `anim.impact_strokes` двумя веерами по бокам (верх кадра — под якорем хука);
   - перед ударом — предвестник: тень растёт (`envelope_fall`), предмет дрожит (`phone_fall`);
   - детали состояния: `anim.eye_bags` (мешки под глазами — ночь, усталость; на чёрном коте — лиловый светлее
     шерсти + дуга тушью), `anim.sweat_drop` (страх, неловкость). Координаты глаз — сеткой.
6. **Камера сцены** (`cam`): `zoom = 1/(1 + 0.12·(1 − SNAP(t/0.3)))` — резкий наезд с первого кадра (>1 — ближе;
   **не наоборот**), тряска после задержки на ударе, толчок `spring`. Окно плана задаётся в reel.json; `fill_windows`
   окно сцены не трогает; за краем ночного рисунка — его стена (отражение).
7. **Проверка — лист до рендера:** `anim.sheet(sc.frame, ctx, [моменты], crop, path)` (≈20 с) → глазами; рендер рилса
   (≈3 мин) — только после чистого листа. Покадрово падение — `ffmpeg -ss i/30` на кадры удара ± 8.
8. **Встроить:** план `{"src": "<А как исходник>", "anim": "<сцена>", "from": [...], "to": [...]}`; якорь хука —
   `{"kind": "mark", "anchor": true, "text": "2–4 слова", "at": 0, "speed": 2.0}` на чистом месте (не на предмете,
   который летит). Тест сцены — `tests/test_anim.py` для общих функций, лист — для сцены.

## Ошибки, которые уже стоили времени (не повторять)

| симптом | причина | как сразу |
|---|---|---|
| след смаза впереди предмета | `cv2.filter2D` — корреляция | `anim.smear` уже правильный, не переписывать |
| двойной контур на сжатии | смесь двух картинок по мягкой маске | только поле смещений (`squash_follow`) |
| кот «худеет» на ударе | `squash_region` с sx = 1 + 0.5·a теряет 3–7% площади | `squash_follow`: sx = 1/sy |
| голова под пальцем отвечает позже удара | запаздывание считалось от пола | `focus` = точка удара; зона удара без запаздывания |
| телефон на морде гнётся при сжатии | твёрдое внутри деформируемой маски | `rigid=[маска]` на рисунке Б |
| в дыре проступает призрак предмета | зерно взято с той же дыры (`grain_from=(0,0)`) | `grain_from="noise"` или сдвиг на чистое место |
| призрак глаз едет за светом | свет = разница рисунков А и Б | свет — гладкое пятно по форме предмета |
| рваный край у лап на стене | замена кусков стеной Б | стена гаснет множителем «яркость Б / яркость А» |
| окно сцены сжато до морды | `fill_windows` подгоняет окно по высоте туши | для `anim` уже отключено |
| наезд начинался ближе и отъезжал | `zoom > 1` — это ближе | старт `1/(1+k)` |
| якорь не нарисовался | событие с `dt < 0` до начала плана не рисуется | `dt: 0`, `speed: 2` |
| якорь лёг на летящий предмет | место выбрано до анимации | якорь там, куда предмет не летит |
| пыль / края вне кадра 9:16 | рисунок 3:2 шире окна в 2 раза | сдвигать детали к центру окна (`PUFF_SHIFT`) |
| конверт без контура клапана | тушь клапана сочтена шерстью | шерсть — ручной полосой у края, тушь не трогать |
| кадр сцены — другой бумаги | сцена отдаёт сырой рисунок | `anim.paper_like` для бумажных рисунков |

Не брать: LaMa на тёмной стене (пятна, полосы — замер 25.10), «резиновое» растягивание фона вокруг предмета, смаз
средним кадров всей картинки, подмену рисунка А на Б посреди движения.
